مشروع مستقل / FreshOps

من الحجز
إلى إدارة يوم العمل.

منصة عمليات لعدة شركات تربط العملاء وحجوزات الخدمات وطاقة الفريق وتوزيع المهام والمدفوعات لشركة تنظيف.

مساهمتي
منصة عمليات متكاملة وعمليات أعمال
التركيز الهندسي
عزل بيانات الشركات والجدولة والتسعير وتوزيع المهام
التقنيات المستخدمة
ASP.NET Core · PostgreSQL · JavaScript · Entity Framework Core

01 / السياق

المشكلة

حجز الخدمة يتجاوز إضافة موعد إلى التقويم. فهو يحتاج إلى سعر مناسب وفريق متاح وحالة عمل واضحة وسجل للمدفوعات. ويجب أن تبقى هذه العناصر متسقة مع تغيّرات يوم العمل.

02 / مسؤولية التنفيذ

مساهمتي

طوّرت مساحة متجاوبة تشمل سجلات العملاء والخدمات والحجوزات والفرق وتوزيع المهام والتسعير والمدفوعات والتقارير. تدعم المنصة عدة شركات وصلاحيات حسب الأدوار ومصطلحات وحقولاً ونماذج وعمليات عمل قابلة للتهيئة.

  1. إنشاء حجز العميل وحساب سعر الخدمة.
  2. التحقق من توفر الفريق وتعيين الموظفين وتنسيق توزيع المهام.
  3. متابعة مراحل العمل والمدفوعات والسجل التشغيلي.

03 / الهندسة

القرارات وراء الواجهة

إبقاء عمل كل شركة ضمن سياقها

تقوم المنصة على بيانات مرتبطة بكل شركة وفحوص للصلاحيات. وتمنح الأدوار المخصصة وصولاً صريحاً إلى الوظائف التي يحتاجها الفريق.

الحفاظ على سعر الحجز القائم

تحفظ الحجوزات أسعار الصرف المستخدمة وقت إنشائها، لتبقى المجاميع السابقة ثابتة عند تغيّر الأسعار. ويتطلب تعديل المبلغ يدوياً صلاحية مناسبة وسبباً موثقاً، لتظل الاستثناءات قابلة للتتبع.

تغيير الإعدادات بطريقة مضبوطة

تمر إعدادات الشركة بمراحل المسودة والتحقق والنشر. وتسمح الإصدارات المتتابعة للإعدادات والعودة إلى آخر إصدار صالح بتطوير قواعد العمل مع الحفاظ على قالب التنظيف الحالي.

04 / النتيجة

ما يقدّمه المشروع

تجمع المنصة الجدولة وسجل العملاء وتوزيع المهام والسجلات المالية والإعدادات في مساحة مترابطة. وتعرض لوحة البيانات التجريبية واجهة فعلية من المشروع المنفّذ.

الخبرة التي يعكسها المشروع

نمذجة مجال الأعمال والوصول إلى بيانات عدة شركات والتحقق من الواجهات البرمجية وعمليات التشغيل وتنفيذ تطبيقات متكاملة.

  • ASP.NET Core
  • PostgreSQL
  • JavaScript
  • Entity Framework Core
