01 / Context

The problem

Customer support needs to be easy to reach while someone is using a product. A website also needs a support experience that reflects its own brand, content, and language.

02 / Ownership

My contribution

I built the application and backend services behind Pektrix, together with its embedded widget experience. The work connects tenant configuration, conversational workflows, messaging, and help content in one customer-facing interface.

  1. Load the website’s support widget and tenant configuration.
  2. Choose a question, conversation, or support guide.
  3. Continue the support experience within the website.

03 / Engineering

Decisions behind the interface

Tenant-aware configuration

Branding and widget behavior belong to the tenant. The public configuration exposes visitor-facing fields, while tenant/session boundaries keep conversations scoped to their context.

Language as part of the experience

English and Arabic support extends beyond a translated label: widget content and presentation need to work within the selected language.

A widget backed by services

The embedded interface is one entry point into the application. Backend services handle the configuration and conversation workflows behind it.

04 / Outcome

What the project delivers

The project delivers an embedded support interface combining questions, messaging, and help content, with configurable tenant experiences. The demo screenshot shows the widget home screen.

Experience this demonstrates

API design, multi-tenant applications, AI integration, and the connection between backend services and a responsive customer interface.
